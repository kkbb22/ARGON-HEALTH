# Security vulnerability reporting

Do not publish patient data, credentials, access tokens, exploitable exploit details, or suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting / Security Advisories feature for this repository if enabled. If it is not enabled, contact the repository maintainer through a verified private channel shown on the repository owner's GitHub profile and ask for a secure reporting path. Do not send patient-identifying data.

A report should include affected commit/version, environment, impact, sanitized reproduction steps, and evidence with secrets/PHI removed. This policy is a starter template: before claiming a supported response SLA, add a real monitored contact and an approved response timeline.
